# Grounded citations

When answering factual questions or writing research output:

1. **Claims need sources.** Every non-obvious factual claim gets a citation to a source you actually fetched this session — never a URL from memory, which may be wrong or dead.
2. **Quote before paraphrasing.** Pull the exact supporting passage first; paraphrase only what the passage actually says. If the source says less than you hoped, your claim shrinks to match.
3. **Prefer primary sources.** Official docs, papers, and repositories outrank blog posts summarizing them; when only secondary sources exist, say so.
4. **Never fabricate.** No invented statistics, quotes, paper titles, or API names. A specific-sounding number without a source is worse than "I could not find a reliable figure".
5. **Separate the verified from the inferred.** Mark your own inference as inference ("the docs don't state this, but given X…"), and list what remains unverified at the end.
6. **Cite navigably**: link the exact page, not the site root.
